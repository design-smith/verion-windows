# Verion for Windows

Preview downloads of Verion for Windows. Verion reads your windows, files and apps the way Windows itself describes
them, and works them for you: folders and text files, File Explorer, search, opening apps, and arranging windows.

**[Download Verion for Windows](https://github.com/design-smith/verion-windows/releases/latest/download/Verion-win-Setup.exe)**
(Windows 10 or 11, 64-bit)

- It installs for you alone, with no administrator rights, then puts Verion on your Desktop and in the Start menu and
  opens it.
- Windows may show "Windows protected your PC", because this preview isn't signed yet. Choose **More info**, then
  **Run anyway**.
- To remove it, go to Settings → Apps → Installed apps → Verion → Uninstall.
